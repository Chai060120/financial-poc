Financial Agent

上传财报或输入公司名，自动给出估值结论，并支持多轮追问。

用法：输入「美的集团 2024」自动下年报；输入「茅台 vs 五粮液」做公司对比。 报告含引用溯源；可点下方「导出报告」下载 Markdown/HTML。

确认上传文件名

Agent 会尽量自动识别公司；文件名含公司名时更稳。可直接用原名，也可改成推荐格式。

推荐格式：美的集团2025年年度报告.pdf
也可带代码：000333.SZ_2025年报.pdf
